# Record source CLI

Use the current source-preview [scope/setup](../release/initial-preview.md),
[English example](../../examples/records-to-review/en.md) or
[French example](../../examples/records-to-review/fr.md). Their a1 wording is
historical; this selected source engine is0.1.0a3. In a prepared environment,
replace the installed executable with python -X utf8 scripts/reconcile.py while
retaining all example arguments. A wheel install is a separate build/install check.

Capture checked originals and explicit scope/authority, reconcile, inspect unknowns,
apply a reviewed correction separately, verify the returned run, then prepare only
a local adviser copy. No sending, account access or professional approval. The
input limits are16MiB/source,32MiB/10000 logical records combined; no prefix acceptance.
A saved incomplete result stays incomplete. No study/focus group is planned.
[Host responsibilities](host-responsibilities.md) and [security status](../../SECURITY.md)
remain relevant; prose does not enforce OS permissions or establish physical data truth.
