# Security policy

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/jeremylongworth-source/AgentAgriculture/security/advisories/new) when the private reporting form is available. Jeremy Longworth triages reports. There is no response SLA.

If the form is unavailable, keep sensitive details private until reporting is enabled. Use public issues for ordinary bugs with invented examples. Keep private farm records, credentials and sensitive logs out of GitHub and AI tools.

In a private report, include the affected version and host, a minimal synthetic reproduction, expected and observed behavior, and the impact.

## Preview scope

The record CLI reads selected local files and writes inspectable local results. Other executable workflow helpers accept invented inputs only. Host permissions and approval enforcement depend on the host and tools. Input bounds and checksum checks establish limited local checks. Professional or regulated use, field benefit and other-host support require separate evidence.
