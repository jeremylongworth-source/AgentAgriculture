# Livestock/feed records for review

Follow the three actual skills in manifest order. The executable path is
[documented here](../../docs/workflows/livestock-record-helper.md). It accepts only
invented normalized evidence, while portable skills can prepare appropriately
authorized supplied records manually. No participant prerequisite is imposed on
generic record preparation. No prescription, clinical diagnosis, ration, professional
validation or welfare clearance is produced. Readiness/evaluation states refer only
to retained finite evidence; a paired baseline and field benefit are separate.

[Source-package setup](SOURCE-PACKAGE.md) includes the complete manual path:
[events](../../skills/farm-livestock-event-review/SKILL.md),
[feed stock](../../skills/farm-feed-stock-review/SKILL.md), then
[local handoff](../../skills/farm-livestock-review-handoff/SKILL.md).
