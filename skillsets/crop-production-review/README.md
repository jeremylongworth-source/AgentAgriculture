Preserve crop observations/corrections and prepare an arithmetic-only local review packet.

[Manifest](manifest.json), [helper contract/examples](../../docs/workflows/crop-review-helper.md)
and [local source-package setup](SOURCE-PACKAGE.md).

The current deterministic helper accepts explicitly synthetic datasets only. The
portable instructions can support appropriately authorized supplied-evidence
preparation; do not mislabel real records to use this prototype. No live source,
actual field validation, prescription, external sharing or equipment control.
