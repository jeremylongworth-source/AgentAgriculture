Help the operator reach one useful record-review result with the tools already in
use. Establish the question before collecting a farm profile. Reuse task context
and authority already supplied.

Read the chosen language's [English intake](../../templates/en/intake.md) or
[French intake](../../templates/fr/intake.md) and mapping guide beside it. Ask only
for missing context that changes this task: enterprise/activity jurisdiction,
inclusive period, currency/basis, selected sources, actual omissions, output language
and intended recipient scope. A known adequate native feature may be the better path.

For selected exports, construct the existing task/input-manifest contracts using
confirmed headers and source digests. Preserve unknowns; never turn a business
address into an activity location or an omitted export into complete coverage.
For checked paper transcription, use the blank `manual-entry.csv` and the `capture`
command described in the chosen language's [English walkthrough](../../examples/records-to-review/en.md)
or [French walkthrough](../../examples/records-to-review/fr.md). Inspect source and
transcription before recording its confirmation. The flag does not check paper.

Confirm only missing material authority or interpretation. Existing authorization
to prepare these selected local records is sufficient for reversible local work.
Keep a useful incomplete task when row-level information is unavailable; do not
invent identifiers, dates, amounts or units to finish it.

Hand off the question, confirmed scope, prepared paths and remaining questions to
record reconciliation. A prepared input folder is not a reconciled or approved
package. Use the [host boundary guide](../../docs/workflows/host-responsibilities.md)
when file persistence, permissions, paper capture or another host is uncertain.
