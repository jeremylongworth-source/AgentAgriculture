---
name: farm-record-reconciliation
description: Reconcile selected local farm CSV records with traceable totals, duplicate review and explicit corrections. Use for matching records or rapprocher des registres, including incomplete exports; it does not perform accounting filings or professional prescriptions.
---

Use the deterministic CLI; do not calculate a replacement result in prose. Read
the selected language's mapping and exception guides under `templates/en/` or
`templates/fr/`, and the [local pipeline guide](../../docs/workflows/local-pipeline.md)
when a command or recovery detail is needed.

Inspect the task, manifest and selected source bytes. Confirm only missing material
scope/mapping details. Run `reconcile` without new corrections first when identity
is unresolved. Inspect `summary.md`, `record-review.md`, `exceptions.json` and the
calculation ledger. Show original text beside each proposed interpretation; retain
source IDs, leading zeros, currency, unit and missing/estimated states.

A receiving row is evidence for quantity comparison, not another purchase. Similar
references are possible duplicates, not permission to delete or merge them. Apply
only explicit compatible decisions in a separate correction file, retaining prior
values, versions and reasons. Never force records to agree or infer a conversion.

After a correction, rerun and verify the committed snapshot. Compare the current
selector, changed calculations and retained old version. An input digest mismatch
requires confirmed new evidence/mapping, not automatic acceptance of changed bytes.
After interruption, retry the same task; pending folders do not establish a save.

Return the verified path, exact checked values, their scope and unresolved questions
in the operator's language. A usable incomplete package is an acceptable result.
Prepare a local adviser copy only when requested; sharing or external acceptance
is never implied by a generated file. The [English](../../examples/records-to-review/en.md)
and [French](../../examples/records-to-review/fr.md) walkthroughs exercise this path.
