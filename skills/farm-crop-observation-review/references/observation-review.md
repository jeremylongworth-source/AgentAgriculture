# Observation and conservative comparison rules

The [crop composition](../../../skillsets/crop-production-review/README.md) contains
the executable invented example. Preserve event vs recording time, entity IDs,
literal crop/stage names, source refs and full correction history. Supersession must
reference an existing compatible event chain with a reason; forks remain conflicts.
As-of review must not use a correction recorded in the future to erase old evidence.

Comparison requires current, observed, measured records with known compatible entity,
metric, exact units/method/basis/sampling-scope declarations and known event times.
Two missing methods do not make a match. Do not convert an estimate, trace or missing
value to measured zero, equate different extraction methods, infer calibration from
an accreditation directory, or claim a sample represents a whole field. A difference
uses exact decimal arithmetic and retains input sources; interpretation is separate.

Primary modeling reference checked 2026-10-17: [farmOS logs](https://farmos.org/model/type/log/)
distinguish event types, planned/done states, revisions and referenced assets/
quantities. This is a design reference, not a farmOS connector, API compatibility
claim or Canadian agronomic authority. No numeric crop-stage or treatment method
is adopted. Obtain the actual applicable method/source when interpretation is needed.
