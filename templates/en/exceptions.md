# Review questions and exceptions

Use the generated `record-review.md` to compare original text, interpreted values,
states, source rows and correction IDs. `exceptions.json` and `summary.md` give a
readable next action for each stable exception code.

| Source row(s) | Original text | Proposed interpretation | Unresolved question / required evidence | Confirmed decision and reason |
| --- | --- | --- | --- | --- |
| | | | | |

A possible duplicate needs an identity decision; keep both originals. An unknown
unit remains outside kilogram totals. A partial export cannot establish a full
enterprise-period total. A receiving discrepancy remains a discrepancy until
evidence resolves it; do not edit a record to force agreement.

Store confirmed corrections separately with exact prior value, record version,
reviewer alias, timestamp and reason. New numeric correction values use a dot
decimal; retain the source convention in the original. An unapplied/conflicting
decision stays visible. Rerun and verify the new snapshot after a correction.
Use [results.md](results.md) even when the useful result is incomplete.
