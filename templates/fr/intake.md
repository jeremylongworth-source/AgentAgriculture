# Dossier de révision — contexte de la tâche

Question à traiter : ____________________

Recueillez uniquement les renseignements manquants nécessaires à cette question :

| Renseignement | Réponse de l’opérateur |
| --- | --- |
| Identifiant de l’entreprise et province ou territoire de l’activité | |
| Dates de début et de fin inclusives | |
| Devise et base (ce processus utilise les pièces d’achat) | |
| Méthode actuelle sur papier ou outil utilisé ; fonction existante déjà suffisante, le cas échéant | |
| Une ou deux sources choisies, en-têtes et identifiants des lignes sources | |
| Éléments inclus ou omis, filtres et couverture complète, partielle ou inconnue | |
| Résultat en anglais ou en français et destinataire prévu | |
| Autorisation existante de lire localement les enregistrements choisis ; échéance éventuelle | |

Ne recueillez ni coordonnées précises, ni mots de passe, ni noms de participants,
ni profil complet de l’exploitation si la tâche n’en a pas besoin. Réutilisez les
réponses et les autorisations déjà fournies.

Pour le papier, copiez [manual-entry.csv](manual-entry.csv), saisissez une ligne
source par ligne et conservez une référence de page et de ligne papier. Comparez
chaque valeur saisie à la pièce avant d’indiquer `--confirm-transcription`. Ce
drapeau consigne la vérification ; le logiciel ne lit pas le papier. Laissez vide
une unité inconnue. Utilisez des identifiants de ligne distincts et conservez les
références commerciales et les zéros initiaux. Une lacune n’est pas un zéro.

Si le périmètre de la tâche est inconnu, conservez ce contexte comme brouillon.
Si le périmètre choisi est connu mais que certaines lignes sont incomplètes,
conservez-les et préparez un résultat partiel. Consultez [mapping.md](mapping.md)
avant de confirmer les champs, puis le [parcours complet](../../examples/records-to-review/fr.md).
