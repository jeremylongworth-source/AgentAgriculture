# Questions et exceptions à réviser

Utilisez le fichier généré `record-review.md` pour comparer texte d’origine, valeurs
interprétées, états, lignes sources et identifiants de correction. `exceptions.json`
et `summary.md` présentent l’action suivante en langage courant pour chaque code
d’exception stable.

Un doublon possible exige une décision d’identité ; conservez les deux pièces.
Une unité inconnue reste hors des totaux en kilogrammes. Un export partiel ne peut
pas établir un total complet de l’entreprise pour la période. Un écart de réception
reste un écart jusqu’à résolution par les pièces ; ne modifiez pas un enregistrement
pour forcer l’égalité.

Conservez les corrections confirmées séparément, avec valeur précédente exacte,
version, pseudonyme du réviseur, horodatage et motif. Les nouvelles valeurs numériques
de correction utilisent le point décimal ; la convention source reste conservée
dans l’original. Une décision non appliquée ou conflictuelle reste visible. Relancez
le traitement et vérifiez le nouvel instantané après correction. Utilisez
[results.md](results.md), même si le résultat utile est incomplet.
