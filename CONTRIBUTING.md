# Contributing

Project-owned source/documentation uses [MIT](LICENSE). Retain
[third-party rights](THIRD_PARTY_NOTICES.md). Contribute only material you may provide.
Use invented fixtures, focused skills and explicit output/source/method contracts.
Preserve source identities, units, unknowns and review boundaries. Deterministic
helpers own calculations; add meaningful scenarios and regressions for changed work.

Follow [setup](README.md), run the ecosystem validator and relevant tests. The
candidate suite covers runtime/routing/domain/source-selection behavior; historical
owner-side profile packaging/qualification records are not distributed as product
requirements. No participant study is planned. Avoid paid services, accounts,
production actions or global setup as incidental changes. No field/safety/financial
approval follows from tests. Do not post private farm records or credentials.

Read [security/reporting status](SECURITY.md) before disclosing vulnerabilities.
No support SLA or publication approval is created by this source candidate.
